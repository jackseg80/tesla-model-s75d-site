# Tesla Model S 75D — préversion Web

Site : https://jackseg80.github.io/tesla-model-s75d-site/

Version B23 : Model S 75D 2017 phase 2, huit familles de fiches, vue assemblée/éclatée, sélection et lecture sans 3D. Le site statique se trouve dans `docs/`. Les prochains ajustements de finition seront ajoutés à ce même dépôt.

Représentation visuelle estimée ; organes mécaniques schématiques. Les informations de la voiture sont datées et distinguent déclarations, historique et inconnues. Galerie définitive et qualification sur appareils réels en cours.
