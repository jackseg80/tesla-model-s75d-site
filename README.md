# Tesla Model S 75D — préversion Web

Site : https://jackseg80.github.io/tesla-model-s75d-site/

Version D03 / B23 : Model S 75D 2017 phase 2, huit familles de fiches, éclatement animé, repères, visite guidée manuelle en cinq étapes et planche de 42 pièces avec recherche et filtres. Lecture sans 3D conservée. Le site statique se trouve dans `docs/` ; les prochaines mises à jour utiliseront la même adresse.

Représentation visuelle estimée ; organes mécaniques schématiques. Les informations de la voiture sont datées et distinguent déclarations, historique et inconnues. Contenus revus le 1er novembre 2026 ; galerie définitive et qualification sur appareils réels encore à compléter.
